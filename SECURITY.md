# Security policy

## Project status

This repository currently contains an early development foundation and is not approved for production use.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in public issues or pull requests. The Ministry-approved private security reporting channel has not yet been provided. Contact the authorized project owner through an approved internal channel and request the designated reporting route; do not send sensitive details through an unapproved channel.

## Safe development

- Never commit credentials, private keys, personal information, or production data.
- Use synthetic data for local development and tests.
- Keep dependencies updated and review automated security alerts.
- Do not deploy or publish the application without explicit authorization and approved infrastructure.
